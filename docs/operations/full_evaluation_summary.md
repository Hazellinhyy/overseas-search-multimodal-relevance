# 公开集300条真实评测摘要

## 运行口径

- 模型：KML 本地 `Qwen3-VL-32B-Instruct`
- 模态：本地视频均匀抽取最多8帧，叠加公开 metadata 中的标题、ASR、OCR
- 数据：300条；293条有效四档 Gold，7条官方“丢弃”；295条有视频，5条文本降级
- 安全：Gold、query含义、人工视频内容说明均未进入 Prompt；无第三方 API
- Prompt：1.0.0 正式 baseline

## 真实结果

- 唯一样本：300
- 成功：291；格式失败：9；失败率：3.00%
- 有效 Gold 评测：284
- QWK：0.42365050255185455
- Exact Accuracy：0.5035211267605634
- ±1 Adjacent Accuracy：0.7359154929577465
- 平均延迟：39823.47 ms
- P50 / P95：38237.88 / 53149.48 ms
- 单模型有效生成吞吐：约0.025 item/s（约0.02 QPS）
- 分层：单 teacher 的 agreement 上限为0.7，因此成功样本全部为 B，未虚构 A 层共识

完整逐条 JSONL/CSV 与包含20条 Case 的报告保存在 Git 忽略的 `artifacts/`、`reports/phase1/`
目录，不提交竞赛数据和 Gold。

## Prompt 1.1.0 候选回归

Prompt 1.1.0 补齐官方四档定义和严格 JSON 约束。固定前10条独立回归中：旧版 QWK
0.923664，新版0.898990；Exact均为0.8，±1均为1.0。新版修正2条，同时使另外2条降档，
样本量不足以证明整体增益，因此不能用该小样本替代完整300条指标。

## 发布判断

Prompt 1.0.0 的全量 QWK 低于评审底线，不能作为最终效果版本。模型选择会直接影响QWK、
视觉增益、延迟和稳定性，但应先基于固定、无Gold泄漏的开发/验证切分校准Prompt，再用相同
帧配置比较候选VLM。未经同口径验证不得仅凭参数规模更换模型或宣称提升。
