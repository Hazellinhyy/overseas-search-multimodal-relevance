# 海外搜索多模态相关性系统方案

## 输入与多模态获取

正式最小输入为 `query + video_url`。服务受控下载视频后均匀抽取最多8张关键帧；批量 ZIP 可按
`sample_id/item_id` 匹配包内视频。标题、ASR、OCR、封面、河图信息和前序视频信息属于可选增强，
缺失时不得编造。视频下载限制 HTTP(S)、域名 allowlist、内容类型与2GiB上限，避免 SSRF 和 ZIP Bomb。

关键帧用于颜色、场景、动作、外观和风格判断；ASR补充口播语义；OCR补充字幕和画面文字；标题
提供召回侧文本背景。看后搜保留前序视频信息，并继续使用既有 Query–Refer、Query–Doc、
Refer–Doc 合成公式，不改变业务规则。

## 模型与策略

正式候选为本地 `Qwen3-VL-32B-Instruct`，运行在获批 KML 4×A100 环境。Mac 只提供本地页面、
抽帧和 SSH 隧道，不调用第三方 AI API。模型输出严格 JSON：四档标签、置信度、理由与证据。

多 teacher 模式通过多个 localhost 端点投票，记录标签分布、一致性和归一化熵。单 teacher 不能
形成真实共识，因此 agreement 上限保守设为0.7，不允许自动进入 A 层。

## 四档标签

- 3：核心实体、主要意图和不可省略限定词均满足。
- 2：核心实体正确，主要需求基本满足，但存在非关键缺失或合理不确定性。
- 1：存在关联，但关键需求未满足。
- 0：核心实体、主题或主要意图不一致。

## A/B/C 分层与人工兜底

分层使用模型置信度、teacher 一致性和证据完整度的保守最小值。无冲突且三项均不低于0.85为A；
不低于0.60为B；其余或存在规则/模态冲突为C。A可进入直接替代候选，但仍需抽检；B可作为基础
训练数据并持续抽检；C不得直接入训，进入三人一致拟合、Gold、badcase和规则校准流程。阈值必须
根据真实公开集/隐藏集校准，不能把模型自报置信度解释成正确率。

## 批处理与输出

支持 JSON、JSONL、CSV、XLSX，或一个数据文件加视频目录组成的 ZIP。任务异步执行，保留进度、
失败原因、重试和断点 JSONL；完成后提供 JSONL、CSV及 summary。Gold字段只在推理完成后用于评测，
从不进入 Prompt。

输出包含标签、置信度、校准置信度、层级、理由、证据、teacher分布、熵、模型版本、Prompt版本、
帧数、延迟和处理状态。评估报告从真实结果生成 QWK、Exact、±1 Adjacent、分层占比、失败率、
吞吐和P50/P95，并最多列出20条真实错误 Case；缺失数据保持 n.a.。

## 生产闭环

结果按 A/B/C 路由到自动入训候选、抽检队列和人工 Gold 队列。人工复核可回写错误类型和规则归因，
形成 badcase 集；新版本在固定回归集、视觉强依赖子集和跨场景子集上对比后才能发布。
